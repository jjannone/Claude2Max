# Claude2Max — Claude Project payload

Everything a Claude.ai Project (or one chat) needs to write Max/MSP patches as JSON specs that build themselves inside Max. No server, no terminal.

| file | what it is | where it goes |
|---|---|---|
| `CLAUDE_INSTRUCTIONS.md` | the Project's custom instructions | paste into the Project's **Instructions** field |
| `SPEC_REFERENCE.md` | the spec format, object notes, examples | upload to the Project's **Files** |
| `examples/*.json` | six specs, each showing something the others don't | upload to **Files** (optional but helpful) |
| `patchgen.js` | the generator that runs inside Max | put beside `patchgen-loader.maxpat` on your computer |
| `patchgen-loader.maxpat` | a ready-made patch: LOAD → pick `spec.json` → new window | open in Max |

Workflow: ask the Project for a patch → save the JSON it returns as `spec.json` → in Max, open `patchgen-loader.maxpat`, click **LOAD**, pick the file → a new window opens with the patch → save it as a `.maxpat`.

This folder is generated by `tools/build_claude_project.py` in the Claude2Max repository — edit the sources there, not here.
